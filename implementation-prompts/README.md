# 📚 Implementation Prompts - راهنمای پرامپ‌های پیاده‌سازی

این پوشه شامل تمام پرامپ‌ها و دستورالعمل‌های لازم برای پیاده‌سازی بازآرایی معماری است.

## 📁 فایل‌های موجود

### 1. `COMPLETE_ROBOT_PROMPT.md` ⭐ **پیشنهادی**
**بهترین انتخاب برای ربات/AI**

- پرامپ کامل و مستقیم
- دستورالعمل‌های گام‌به‌گام
- کدهای کامل آماده استفاده
- مناسب برای اجرای خودکار

**استفاده:** این فایل را مستقیماً به ربات/AI بدهید.

---

### 2. `FULL_IMPLEMENTATION_PROMPT.md`
**راهنمای کامل با توضیحات**

- شامل تمام جزئیات
- توضیحات کامل برای هر فاز
- کدهای کامل با کامنت
- مناسب برای مطالعه و درک کامل

**استفاده:** برای مطالعه کامل و درک عمیق از پروژه.

---

### 3. `IMPLEMENTATION_PROMPT.md`
**راهنمای فارسی کامل**

- تمام دستورالعمل‌ها به فارسی
- کدهای نمونه TypeScript
- مراحل پیاده‌سازی گام‌به‌گام
- چک‌لیست تست

**استفاده:** برای توسعه‌دهندگان فارسی‌زبان.

---

### 4. `QUICK_IMPLEMENTATION_GUIDE.md`
**راهنمای سریع انگلیسی**

- خلاصه مراحل
- دستورالعمل‌های کوتاه
- مناسب برای مرور سریع

**استفاده:** برای مرور سریع و یادآوری.

---

### 5. `AI_AGENT_PROMPT.txt`
**پرامپ ساده و مستقیم**

- پرامپ کوتاه و مستقیم
- شامل تمام الزامات
- ساختار ساده

**استفاده:** برای AI agents که نیاز به پرامپ کوتاه دارند.

---
